1. Quién es el responsable

DatoVortice es un canal de YouTube de historia, geografía y curiosidades (youtube.com/@DatoVortice). El titular del canal es el responsable de la herramienta de automatización descrita en esta web y de esta política.

La herramienta es una aplicación de escritorio de uso propio: no se comercializa, no se ofrece a terceros y no tiene registro ni inicio de sesión para visitantes. El único usuario es el titular del canal, que acepta esta política al autorizar el acceso a su propia cuenta de Google. Esta aplicación utiliza los servicios de la API de YouTube.

2. Datos que obtenemos de la API de YouTube

La herramienta utiliza la API de YouTube Data v3 con dos permisos (ámbitos OAuth): youtube.upload (subir vídeos) y youtube.readonly (consultar datos del propio canal). A través de ellos solo realiza estas operaciones, siempre sobre el canal de DatoVortice:

  • Consulta del canal (channels.list): identificador, nombre y @handle del canal autorizado, para comprobar que es el correcto antes de subir nada.
  • Subida de vídeos (videos.insert): se envía a YouTube un vídeo propio ya aprobado, con su título, descripción, etiquetas, visibilidad y fecha de programación. YouTube devuelve el identificador del vídeo.
  • Consulta de vídeos propios (videos.list): visibilidad, fecha de programación, estado de procesamiento y duración de vídeos de nuestro canal, para confirmar que una subida o programación se ha aplicado.

Lo que no hacemos. No obtenemos ni tratamos datos de espectadores, suscriptores, comentarios, estadísticas de audiencia, correos ni contraseñas, ni datos de ninguna otra cuenta. Aunque el permiso youtube.readonly permitiría leer más datos de la cuenta, la herramienta no realiza ninguna otra llamada que las tres anteriores. La herramienta nunca recibe la contraseña de Google: el inicio de sesión ocurre en el navegador, en accounts.google.com.

3. Para qué los usamos

Exclusivamente para gestionar el propio canal: comprobar que se autoriza la cuenta correcta, subir vídeos propios (siempre primero en privado), programar su publicación, verificar su estado y evitar subir el mismo vídeo dos veces. No usamos estos datos para publicidad, elaboración de perfiles, venta, estudios de mercado ni ningún otro fin. No utilizamos los datos obtenidos de las API de Google para desarrollar, mejorar ni entrenar modelos de inteligencia artificial o aprendizaje automático.

No existe ningún servidor, base de datos ni almacenamiento en la nube propios. Todo se guarda localmente en el ordenador del titular:

5. Cómo protegemos las credenciales

Describimos lo que realmente hacemos, sin más:

  • Las credenciales y los tokens se guardan fuera del código del proyecto, en la carpeta de usuario de Windows del titular, y están excluidos del control de versiones. El código y los archivos de esta web no contienen ningún secreto.
  • La carpeta tiene permisos de Windows que limitan el acceso al propio usuario, al sistema y a los administradores del equipo.
  • El inicio de sesión usa OAuth 2.0 para aplicaciones de escritorio con PKCE, en el navegador. Las comunicaciones con los servidores de Google usan HTTPS.
  • La herramienta no muestra tokens ni secretos en pantalla ni en sus registros.
  • Limitación importante: la aplicación no cifra por sí misma el archivo del token de renovación; depende de los permisos de Windows y de la protección general del equipo del titular. No afirmamos que esos archivos estén cifrados.

6. Servicios externos y terceros

No vendemos, cedemos ni transferimos datos obtenidos de las API de Google a terceros con fines de publicidad, intermediación de datos o elaboración de perfiles. Estos son los servicios externos que intervienen en el trabajo del canal y lo que reciben:

ServicioQué recibe
Google / YouTubeLos vídeos, títulos, descripciones y fechas de programación que subimos; el inicio de sesión se hace directamente con Google.
ElevenLabs (voz sintética)Únicamente el texto de la narración de cada vídeo. No recibe datos de la API de Google ni tokens.
Wikimedia Commons, OpenStreetMap y Natural EarthConsultas o descargas de imágenes y datos de mapas públicos, con una identificación genérica del canal. No reciben datos de Google ni datos personales.

GitHub (GitHub Pages)Aloja esta web estática. Como cualquier alojamiento, puede registrar datos técnicos de acceso, como la dirección IP, según su propia política. No hay ningún dato de la API de Google en la web.

La política de privacidad de Google se encuentra en policies.google.com/privacy. Al usar la herramienta, el titular acepta además los Términos del servicio de YouTube y las Políticas para desarrolladores de los servicios de la API de YouTube.

7. Uso limitado de datos de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google se ajustará a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
DatoVortice's use and transfer to any other app of information received from Google APIs will adhere to Google API Services User Data Policy, including the Limited Use requirements.

8. Eliminación de datos

Puedes pedir en cualquier momento que eliminemos los datos almacenados escribiendo al correo de la sección 11. Los eliminaremos en un plazo máximo de 7 días naturales desde la solicitud o desde la revocación del acceso. Eliminar los datos consiste en:

  1. Borrar de la carpeta de usuario los archivos del token de renovación, del canal y de las credenciales del cliente, junto con sus copias de seguridad locales.
  2. Borrar el registro local de vídeos subidos.
  3. Revocar el acceso en la cuenta de Google (sección 9), de modo que el token deje de ser válido.

Borrar estos archivos no elimina los vídeos ya publicados en YouTube: esos se gestionan desde YouTube Studio.

9. Revocar la autorización de Google

Puedes retirar el acceso de la aplicación en cualquier momento, sin pasar por nosotros, desde la configuración de tu cuenta de Google:

  • myaccount.google.com/permissions
  • security.google.com/settings/security/permissions

La herramienta no incluye un botón propio de revocación: se revoca desde Google. Tras la revocación, el token guardado deja de funcionar y lo eliminamos conforme a la sección 8. Más información sobre las políticas de la API: Políticas para desarrolladores de YouTube.

10. Cookies y rastreo en esta web

Esta web es estática: no usa cookies, ni analítica, ni anuncios, ni herramientas de seguimiento, ni fuentes ni scripts de terceros, y no permite que terceros sirvan contenido o anuncios. No tiene formularios, cuentas ni base de datos.

11. Contacto

Responsable: el titular del canal DatoVortice. Para preguntas, quejas sobre privacidad o solicitudes de eliminación de datos: osetedani@gmail.com, o a través del canal youtube.com/@DatoVortice.

12. Cambios en esta política

Si cambia el funcionamiento de la herramienta, actualizaremos esta página y la fecha de la parte superior. Cualquier ampliación de los permisos de acceso a datos de Google requeriría nueva autorización expresa del titular.
